# Сайт ИВП, первая очередь

Next.js, статическая генерация где возможно, Postgres. Деплой на Vercel.

Что осталось за заказчиком - в [OTKRYTYE-VOPROSY.md](./OTKRYTYE-VOPROSY.md).

## Запуск

```
npm install
cp .env.example .env    # заполнить своими значениями
npm run db:migrate
npm run dev
```

Строка подключения к базе в репозиторий не попадает: репозиторий публичный,
`.env*` под `.gitignore` с первого коммита. Настоящие значения живут только в
локальном `.env` и в переменных окружения проекта на Vercel.

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `DATABASE_URL` | Подключение к Postgres |
| `NEXT_PUBLIC_SITE_URL` | Адрес сайта, попадает в письма и партнерские ссылки |
| `ADMIN_TOKEN` | Вход в админку: `/admin?token=...` |
| `LEADS_EMAIL` | Почта, на которую уходят заявки |
| `ALLOW_DEV_PAYMENTS` | `1` включает кнопку "считать оплаченным" на боевом стенде |

## Где что лежит

| Путь | Что |
| --- | --- |
| `src/config/site.ts` | Адрес сайта, адреса всех страниц, контакты. Переезд на свой домен - замена одного значения |
| `src/config/partner.ts` | Ставки 20 и 10 процентов, срок cookie, база расчета вознаграждения |
| `src/config/products.ts` | Витрина и цены |
| `src/lib/payments/` | Прием оплаты. Сейчас одна реализация - заглушка |
| `src/lib/email/` | Отправка писем. Сейчас складывает в базу |
| `src/lib/orders.ts` | Заказы, закрепление за партнером, начисления |
| `src/middleware.ts` | Партнерская метка `?ref=КОД` |
| `db/migrations/` | Миграции, прогоняются `npm run db:migrate` |

## Индексация

Закрыта целиком и тремя способами сразу: мета-тег на всех страницах, заголовок
`X-Robots-Tag` и `robots.txt`. Открывать только по отдельной команде заказчика.

## Оплата

На этом этапе не подключена. Кнопка ведет на страницу "здесь будет оплата",
заказ при этом создается и сохраняется. В режиме разработки там же есть кнопка
"считать оплаченным": без нее не проверить сценарий с партнерской меткой.

Подключение настоящего эквайринга - вторая реализация интерфейса
`PaymentProvider` (`createPayment` / `handleWebhook`), а не переписывание.

## Партнерская механика

Ссылка вида `/atlas?ref=КОД`. Код кладется в cookie на 180 дней и снимается с
адреса. При оформлении заказа код записывается в сам заказ: подтверждение
оплаты от платежной системы приходит без браузера покупателя.

При оплате, если у покупателя еще нет закрепления, оно создается и запирается
навсегда. Начисление: 20 процентов с первой покупки этого покупателя, 10 со
всех последующих. Статус при создании - "ожидает подтверждения", в "к выплате"
переводится вручную из админки.

Закрепление защищено триггером в самой базе: UPDATE и DELETE по запертой строке
отклоняются.
